# אתר קובה אליהו

אתר סטטי (HTML/CSS/JS). הוא מתארח ב-Cloudflare Pages ומתעדכן אוטומטית מכל שינוי כאן ב-GitHub.

## איך מעדכנים בלי מתכנת

| מה רוצים לשנות | איפה |
|---|---|
| להוסיף או להסיר חנות או בית עסק | `stores.csv`: שורה לכל חנות (עיר, שם החנות, כתובת) |
| מספר וואטסאפ או מייל | `config.js` |
| דף הבית (תמונות מתחלפות + הסיפור של סבתא) | `index.html` |
| המוצרים | `products.html` |
| איפה קונים | `where.html` |
| לעסקים (כולל טופס הצעת מחיר) | `business.html` |
| צור קשר (פניות הציבור) | `contact.html` |
| לאיזה מייל מגיעות הפניות מהטפסים | `config.js` (formEmail) |
| מתכונים | `recipes.html` |
| הקטלוג העסקי | מחליפים את `catalog-kube-eliyahu.pdf` בקובץ חדש באותו שם |

עריכה ב-GitHub: פותחים את הקובץ, לוחצים על אייקון העיפרון, משנים ולוחצים Commit changes. תוך כדקה האתר מתעדכן.
